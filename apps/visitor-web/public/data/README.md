# Dam Sen OSM research snapshot

`damsen-osm-walkways.geojson` contains public `footway`, `path` and
`pedestrian` ways located inside OpenStreetMap way `32735046` (Công viên Văn
hóa Đầm Sen).

- Source: OpenStreetMap contributors, licensed under ODbL.
- Retrieved through Overpass on 2026-09-27.
- Scope: 54 ways and 360 graph nodes.
- Purpose: local study/demo and visual reference.
- Verification: not field surveyed; closures, access rules, surfaces and
  wheelchair suitability may be missing or outdated.
- Navigation: do not treat this snapshot as authoritative real-world guidance.

The visible map must retain `© OpenStreetMap contributors` attribution.
